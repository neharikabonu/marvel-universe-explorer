# Marvel Universe Explorer

A cinematic and responsive React application for exploring Marvel characters, their stories, powers, relationships, movies, series, and comics.

## Live Demo: https://neharikabonu.github.io/marvel-universe-explorer/

## Features

- Cinematic Marvel-themed landing page
- Character search and filtering
- Detailed character profiles
- Powers and abilities
- Character origins and identities
- Family, friends, allies, villains, and relationships
- Movies, series, and comics
- Actors and character versions
- Spider-Man timelines
- Related character navigation
- Responsive design
- Custom 404 page
- GitHub Pages deployment

## Getting Started

Clone the repository:

    git clone https://github.com/neharikabonu/marvel-universe-explorer.git

Navigate to the project:

    cd marvel-universe-explorer

Install dependencies:

    npm install

Start the development server:

    npm run dev
